从发现，到开玩

内容很轻，乐趣不打折。

PCK 是 Godot 游戏内容包，不是独立应用，也不是网页游戏。本页仅提供浏览与下载，不能在浏览器中直接开玩。

请使用与卡片标注引擎版本兼容的 Godot 播放器。下载后的文件需由播放器导入并加载。

  1. 选一款喜欢的游戏
    查看介绍、标签与引擎版本。
  2. 下载 PCK，导入兼容播放器
    或使用已安装的 gamestop CLI 下载并校验大小和 SHA256。
gamestop list
gamestop download --id <游戏 ID> --file ./game.pck

游戏 ID 可在公开清单中查看。公开内容无需 Token；请勿在网址中传递凭据。

让成绩留下名字

把你的成绩记到账号上。

不登录也能玩，成绩只存在本机。想要上榜、换设备也不丢，需要三步：

  1. 注册账号
    填用户名与密码即可提交，需要管理员审核后才生效。
  2. 登录并签发 Token
    审核通过后在我的账号里签发一个 Token；明文只显示一次，请立即保存。
  3. 在播放器里绑定
    鸿蒙 App 的「设置 → 玩家账号」粘贴 Token；之后本机启动的游戏成绩就记到该账号。

已经注册？去登录。还没有账号？去注册。

Token 只保存在播放器的应用私有存储里，不会写进日志、网址或游戏包；游戏拿到的是每局现换的一小时短期凭据。账号名会显示在公开排行榜上，请不要使用真实姓名等敏感信息。

鸿蒙播放器接入

让播放器连到这个服务。

Game Stop 播放器把「谁提供游戏包」和「谁记录账号与成绩」当成同一件事：游戏源地址。把下面的地址加成一个源并启用，播放器就会从这个站点拉清单、下游戏、报成绩。

游戏源名称Game Stop SaaS（名称随意，只用于自己识别）
游戏源地址https://game-stop.giveme8.com/
清单地址https://game-stop.giveme8.com/gamesource/v1/index.json

同一时刻只启用一个源。这个站点与更早的 https://game-stop.baobaobao.online 是两个独立实例：账号、成绩、Token 都不通用，切换源等于切换平台。

操作步骤
  1. 打开播放器设置
    进入「设置 → 游戏源」，新增一条，地址填上面的游戏源地址，先点「测试连接」。
  2. 启用这一条
    把它设为当前激活源。播放器随后重新拉取清单，公开游戏会出现在游戏库里。
  3. 想要上榜（可选）
    先在本站注册（需管理员审核），审核通过后登录并在我的账号签发 Token。
  4. 绑定 Token
    回到播放器「设置 → 玩家账号」粘贴 Token。之后启动的游戏成绩会记到这个账号；明文 Token 只显示一次。

游戏源必须是 https 才允许携带账号凭据；本站全程 HTTPS。菜单名称以你手上的播放器版本为准——播放器客户端不在本开源仓库内。

创作者上传

用 CLI 上传游戏包。

发布流程是「打包 → 本机自检 → 上传 → 切公开」。上传需要 API Token；Token 从注册（经管理员审核）后的我的账号页签发，明文只显示一次。

1. 拿到 gamestop CLI

从 Releases 下载对应平台的可执行文件，或自行构建：

git clone https://github.com/giveme8/game-stop.git
cd game-stop/server
go build -o gamestop ./cmd/gamestop

2. 提供 Token（只放环境变量）

export GAMESTOP_TOKEN=gs_…        # PowerShell: $env:GAMESTOP_TOKEN='gs_…'

不要把 Token 写进仓库、命令参数或共享日志；它等同于你的账号权限。

3. 打包成 .game 容器

容器是标准 zip，元数据的唯一真源是包内 game.json：

my-game.game
├── game.json          必需：id/标题/引擎版本
├── assets/cover.png   必需：封面（png/jpg/webp，建议 3:2）
└── content/game.pck   必需：Godot 内容包

4. 自检并上传

gamestop verify --id my-game --file ./my-game.game
gamestop upload --server https://game-stop.giveme8.com \
  --id my-game --file ./my-game.game
gamestop visibility --server https://game-stop.giveme8.com \
  --id my-game --visibility public

只想发裸 PCK 时，改用 --file ./my-game.pck --metadata ./metadata.json（元数据写在 metadata.json 里）。用 gamestop show 核对线上版本，gamestop list 查看自己的游戏。

上限与常见问题

.game 容器≤ 32 MiB（含解压后的元数据、PCK 与封面合计）。更大的游戏请发裸 PCK。
裸 PCK≤ 95 MiB。这是本站所依赖平台对单个请求体的限制，不是账号或套餐可以自行调高的额度。
默认可见性新游戏默认私有，必须显式执行 visibility --visibility public 才会出现在公开库。
服务端会校验什么容器路径、加密、符号链接、解压体积、可执行扩展名，包内 PCK 的结构与引擎版本，并自行计算大小与 SHA256——包里声明的一律不采信。
覆盖更新相同 --id 再次上传即替换（仅所有者可写）；旧版本对象不会立即回收。

发布前请确认你有权分发该游戏及其素材。平台原创代码采用 Apache-2.0，不覆盖你上传的游戏内容。
